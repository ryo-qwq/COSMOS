# COSMOS ダッシュボード システム概要・要件定義書

## 1. プロジェクト概要

**COSMOS**（宇宙線ミューオンで山の水分量を可視化する土砂災害予測システム）の次期発表および検証に向けた、ブラウザベースの統合ダッシュボードアプリケーションを構築する。

本システムは以下の2つのダッシュボードを1つの Web アプリケーション内でシームレスに切り替えられる構成とする。

1. **実験用ダッシュボード（塩化ビニル管・砂の含水量測定実験）**
   - CosmicWatch v2 ミューオン検出器を用いた室内実験（塩ビ管＋砂＋水）の計測・データ前処理・統計解析・可視化を行う。
2. **運用用ダッシュボード（トンネル常設・山体水分量リアルタイム監視＆土砂災害予測）**
   - 名護大北トンネル等の山岳トンネルに検出器を常設し、LPWA 通信で集約したミューオンデータと気象データから山内部の水分量・土砂災害危険度を可視化し、住民への警報伝達までをイメージできる運用画面を提供する。

## 2. 推奨技術スタック

発表会場でのデモの確実性（オフライン動作・即時起動）、グラフ・アニメーション表現力、および CosmicWatch 実機との連携性を考慮し、以下のフロントエンド中心の SPA 構成を採用する。

| 項目 | 採用技術 | 選定理由 |
|---|---|---|
| フレームワーク | **React 19 + TypeScript + Vite** | 高速な開発・ビルド、型安全性、静的配信（GitHub Pages 等）への対応が容易 |
| スタイリング | **Tailwind CSS** | 発表用スクリーンで視認性の高いダーク基調の防災・計測 UI を迅速に構築可能 |
| グラフ・可視化 | **Recharts** + カスタム SVG / Canvas | 時系列・ヒストグラム・検量線グラフと、塩ビ管／山体断面の直感的なアニメーション表現を両立 |
| アイコン | **Lucide React** | 計測・防災・通信ステータス用の統一感ある UI アイコン |
| 実機通信 | **Web Serial API**（Chrome / Edge） | PC に接続した CosmicWatch（9600 baud）をブラウザから直接受信・CSV 保存可能 |
| 統計解析・前処理 | TypeScript 実装（ブラウザ内完結） | CSV パース、重複・異常行除去、デッドタイム補正、Mann–Whitney U 検定・KS 検定をサーバー不要で即時実行 |

## 3. 対象データ仕様（CosmicWatch v2 準拠）

`CosmicWatch/cosmicwatch.py` および Arduino ファームウェア（`OLED.ino` / `SDCard.ino`）の出力形式に完全準拠する。

### 3.1 CSV カラム定義
```csv
pc_time,event,ardn_time_ms,adc,sipm_mV,deadtime_ms,temp_C
2026-09-24T14:26:13.136,1,3204,120,23.58,0.0,23.15
```

- `pc_time`: PC 側記録時刻（ISO 8601）
- `event`: 検出器が採番するイベント番号（連番）
- `ardn_time_ms`: マイコン内部時刻 [ms]
- `adc`: 生 ADC 値（0〜1023。1023 張り付き時は A0 故障アラート対象）
- `sipm_mV`: SiPM 出力電圧 [mV]（粒子がシンチレータで失ったエネルギーに対応）
- `deadtime_ms`: 累計デッドタイム [ms]
- `temp_C`: 基板温度 [°C]

### 3.2 基本算出式
- **実測ライブ時間**: $\text{live\_s} = \frac{(\text{ardn\_time\_ms}_{\text{last}} - \text{ardn\_time\_ms}_{\text{first}}) - (\text{deadtime\_ms}_{\text{last}} - \text{deadtime\_ms}_{\text{first}})}{1000}$
- **デッドタイム補正済み計数率**: $\text{rate} = \frac{\Delta \text{event}}{\text{live\_s}} \times 60 \text{ [events/min]}$
  - 欠落行がある場合でも、`event` 番号の増分と `ardn_time_ms` を用いることで正確な計数率を算出する。

## 4. 機能要件

### 4.1 共通機能
- **モード切替ナビゲーション**: ヘッダーから「実験用ダッシュボード」「運用用ダッシュボード」をワンクリックで切替可能。
- **発表・プレゼン向け UI**: プロジェクター投影でも見やすい高コントラストなダークテーマ、数値の大型 KPI 表示、日本語 UI。
- **オフライン完結**: 外部 API に依存せず、ローカル環境や静的サイト上で確実に動作すること。

---

### 4.2 実験用ダッシュボード（塩化ビニル管・砂の含水量測定実験）

発表資料で挙げられた実験結果の可視化と「記録不具合の解消・段階的含水量比較・2段重ね同時計数」の検証を一体化する。

#### A. データ入力・計測モード
1. **CSV アップロード＆複数条件比較**
   - `cosmicwatch_*.csv` ファイルをドラッグ＆ドロップで複数読み込み可能。
   - 各データセットに実験条件（例：砂なし、乾燥砂 0%、含水率 10% / 20% / 30%）、砂層厚さ [cm]、砂質量 [kg]、検出モード（単独 MASTER / 2段重ね同時計数 SLAVE）を設定可能。
   - 初回アクセス時からすぐに発表・確認できるよう、**実測サンプルデータ（琉球大学実験ベース＋段階的含水量デモデータ）をプリセット搭載**する。
2. **実機ライブ計測（Web Serial API）**
   - ブラウザから USB シリアル接続（9600 baud）し、スペース区切り／カンマ区切り両形式をリアルタイムパース。
   - バナー行から検出器名および動作モード（`MASTER` / `SLAVE (coincident events only)`）を自動認識して表示。
   - 記録の重複・欠落を防ぎながらブラウザメモリへ逐次蓄積し、クリーンな CSV としてダウンロード可能。
   - `adc == 1023` 連続発生時などの異常検知アラート（railed-A0 診断支援）。
3. **発表用リプレイ／シミュレーションモード**
   - 実機未接続時でも、塩ビ管内の砂の含水率（0%〜30%）や測定モード（単独 / 同時計数）を変更しながらリアルタイムにイベントがカウントされていく様子をデモ再生可能。

#### B. 自動前処理・データ品質チェック
- **自動クレンジング**:
  - 重複行の自動除外
  - 温度異常行（設定可能、デフォルト 20〜30°C 外）およびフォーマット破損行の除外
  - イベント番号の飛び（欠落区間）の検出と記録率（%）の算出
- **品質サマリーテーブル**: 条件ごとの「記録行数 / 重複行 / 壊れた行 / 有効記録数 / イベント数 / 記録できた割合（%）」を一覧表示。

#### C. 可視化・統計解析パネル
1. **塩ビ管実験装置の断面ビジュアライザー**:
   - 塩ビ管・砂層（含水率に応じた色変化）・検出器（1台 / 2段重ね）と、通過／吸収されるミューオン粒子のアニメーション表示。
2. **SiPM 出力分布ヒストグラム**:
   - 複数条件を重ねて表示（横軸：SiPM 出力 [mV] 対数スケール対応、縦軸：イベント割合 [%]）。
   - **閾値スライダー**（デフォルト 50 mV）により、高エネルギーイベントの切り出し比率をインタラクティブに確認可能。
3. **条件別計数率比較グラフ**:
   - 全イベント vs 閾値超（50 mV 超）イベントの計数率および「砂なし基準に対する相対割合（%）」を棒グラフで比較。
4. **統計的検定パネル**:
   - 条件ペアごとの **Mann–Whitney U 検定**、**Kolmogorov–Smirnov（KS）検定**、**比率検定** の $p$ 値を自動計算しマトリクス表示（$p < 0.05$ を有意差ありとしてハイライト）。
5. **含水率と減衰率の相関（検量線）グラフ**:
   - 含水率（0%, 10%, 20%, 30%）または単位面積あたり質量に対するミューオン計数率・出力減衰の関係をプロット。

### 4.3 運用用ダッシュボード（トンネルのある山での土砂災害予測）

名護大北トンネル等の山岳トンネル常設運用をイメージし、「従来の降雨量判断」と「COSMOS による山体内部水分量の直接把握」の違いを一目で伝えられる構成とする。

#### A. 山体・トンネル断面リアルタイムビジュアライザー
- 山の断面図と直下のトンネル、設置された2段重ねミューオン検出器を描画。
- 降雨の強さ、山内部へ浸透していく水分量（ヒートマップ／水位グラデーション）、山を透過する宇宙線ミューオン粒子（水分量増加に伴い途中で減衰・吸収される演出）をリアルタイムにアニメーション表示。
- トンネル外基準に対するミューオン減衰率（例：平常時 -35%、豪雨後さらに -20%）を直感的に表示。

#### B. 広域観測拠点モニター（LPWA ネットワーク）
- 名護市・やんばるエリアを想定した複数トンネル／斜面観測点（例：名護大北トンネル、やんばる北トンネル、羽地ダム周辺斜面など）のマップ／リスト表示。
- 各拠点のステータス（稼働状況、LPWA 通信状態、バッテリー残量、検出器温度、現在の危険度レベル）を表示し、拠点をクリックして詳細監視画面を切替可能。

#### C. 計測データ連動グラフ＆危険度判定 AI パネル
1. **マルチ指標時系列グラフ**:
   - ミューオン透過率（計数率・SiPM 出力変化）
   - 推定山体内部水分量 [%]
   - 降雨量 [mm/h]（比較指標）
   - 地盤変位 [mm]（将来連携指標）
2. **危険度判定 AI スコア＆4段階警戒レベル**:
   - `レベル1：平常（緑）` / `レベル2：注意（黄）` / `レベル3：警戒（橙）` / `レベル4：危険・避難指示（赤）`
   - AI 判定の根拠（例：「降雨は弱まったが、山内部の水分量が飽和域（78%）を維持しており、ミューオン透過率が基準比 -22% 低下中 → 遅発性土砂崩れリスク高」）をテキストで明示し、降雨量のみでの判断との優位性を可視化。

#### D. 住民伝達・警報連携プレビュー
- 警戒レベル上昇時に、自治体（名護市防災担当）・沖縄気象台・Jアラート連携を想定した警報発令バナーおよび**住民向けスマートフォン緊急速報プレビュー**を表示。

#### E. 発表用シナリオシミュレーター
- プレゼン中に審査員へ変化を実演するための操作パネル：
  - **プリセットシナリオ**:
    1. 晴天・平常時（山内部乾燥、透過率安定）
    2. 通常降雨（表面湿潤、安全域）
    3. 線状降水帯・記録的豪雨（水分量急上昇・警戒〜危険発令）
    4. 豪雨翌日・遅発性リスク（雨は止んだが山内部に水が残留し危険継続 — COSMOS ならではの価値を実演）
  - **手動コントロール**: 降雨量スライダー、経過時間シークバー、シミュレーション再生／一時停止／倍速切替。

各フェーズ完了ごとに動作確認を行い、適切なコミットメッセージで記録する。

6. **Phase 5**: **運用用ダッシュボード**実装（山体・トンネル断面ビジュアライザー、LPWA 拠点モニター、時系列グラフ、AI 危険度判定、警報・スマホ通知プレビュー、シナリオシミュレーター）
7. **Phase 6**: 発表向け UI ポリッシュ、レスポンシブ調整、全体動作確認・ビルド検証
