# COSMOS ダッシュボード

**宇宙線ミューオンで山の水分量を可視化する土砂災害予測システム（COSMOS）** の次期発表・検証向けブラウザダッシュボードです。

## 主な機能

### 1. 実験用ダッシュボード（塩化ビニル管・砂の含水量測定）
- **塩ビ管・砂層 断面ビジュアライザー**: 含水率に応じた砂の色変化・ミューオン粒子透過アニメーション・単独（`MASTER`）／2段重ね同時計数（`SLAVE`）表示。
- **CosmicWatch 実機ライブ計測（Web Serial API）**: Chrome / Edge から USB 接続（9600 baud）してリアルタイム計測。Arduino IDE シリアルモニタを閉じてから接続してください。発表用の**デモライブ計測モード**も搭載。
- **CSV アップロード＆複数条件比較**: `cosmicwatch_*.csv` および Arduino 生シリアル出力（スペース／カンマ区切り両対応）を読み込み可能。
- **生データ非破壊・ローカル保存**: 削除機能は一切設けず、読み込んだ CSV や実機計測データはすべてブラウザの IndexedDB にローカル自動保存されます。任意のタイミングで生 CSV としてローカル PC へ保存可能。
- **解析・統計検定**: SiPM 出力分布ヒストグラム（対数ビン・閾値スライダー付き）、基準比計数率比較、含水率 vs 減衰率検量線、Mann–Whitney U / KS / 比率検定 $p$ 値マトリクス、非破壊データ品質サマリー表。

### 2. 運用用ダッシュボード（山岳トンネル常設・土砂災害予測）
- **山体・トンネル断面ビジュアライザー**: 名護大北トンネル等を想定した山体内部水分ヒートマップ、降雨エフェクト、2段重ね検出器、ミューオン透過減衰のリアルタイム表現。
- **危険度判定 AI ＆ 住民伝達プレビュー**: 4段階警戒レベル、「従来の降雨量判断」と「COSMOS による山体水分量判断」の比較、Jアラート・名護市防災連携を想定したスマホ緊急速報プレビュー。
- **発表用シナリオシミュレーター**: 晴天・通常降雨・線状降水帯豪雨・**豪雨翌日の遅発性リスク**の4プリセット、24時間再生シークバー、手動降雨上乗せスライダー、LPWA 4拠点切替。

## セットアップ・起動方法

```powershell
npm install
npm run dev
```

ブラウザで表示されたローカル URL（例: `http://localhost:5173`）を開いてください。

## ビルド

```powershell
npm run build
```
